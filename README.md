# Conversational Workflow Builder

A chatbot that turns a natural-language automation request into a structured
workflow (nodes + edges). Planning and representation only — no execution of
workflows or real integrations.

Status: scaffolding in progress (Phase 0). Full setup instructions,
architecture diagram, and sample conversations will be added here as the
project is built out.

## Folders

- `server/` — Express backend (see `server/.env.example` for required env vars)
- `client/` — React + Vite + Tailwind frontend
