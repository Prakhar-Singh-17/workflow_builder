# Conversational Workflow Builder

A chatbot that turns a natural-language automation request into a structured
workflow (nodes + edges). Planning and representation only — no execution of
workflows or real integrations.

Status: work in progress. Full setup instructions, architecture diagram, and
sample conversations will be added here as the project is built out.

## Folders

- `backend/` — Express backend
- `frontend/` — React + Vite + Tailwind frontend
- `.env` (project root, gitignored) — shared config for both packages; copy
  `.env.example` to `.env` and fill in your own values
